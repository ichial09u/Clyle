SupaPlay Video API

Anime, Movie, and MW ArtPlayer Embed API

SupaPlay lets you embed anime episodes, movies, and MW detailPath players using simple iframe URLs. Use the classic /stream/s-2 endpoint for episode player IDs or the /mw endpoint for ArtPlayer detailPath embeds with seasons, episodes, language switching, and iframe sync.

If you already collect or scrape episode/player IDs from Anikoto or HiAnime-style sources, they use the same type of episode library format, so SupaPlay can work with those IDs.

SupaPlay Features

  • Simple anime episode iframe embed URL.
  • Supports both subtitled and dubbed episode versions.
  • New MW ArtPlayer endpoint for movies, shows, anime, seasons, and episodes.
  • MW iframe supports next episode, previous episode, autoplay, auto-next, language switching, and parent iframe control.
  • Works with episode/player IDs from Anikoto or HiAnime-style episode libraries.
  • Ready for anime websites, episode pages, watch pages, and custom player wrappers.

Classic Episode Endpoint

Use this iframe endpoint to embed an anime episode by player ID:

https://supaplay.fun/stream/s-2/{episode_embed_id}/{language}

Example iframe embed

<iframe src="https://supaplay.fun/stream/s-2/2142/sub" width="100%" height="500" frameborder="0" scrolling="no" allow="autoplay; fullscreen; picture-in-picture" allowfullscreen></iframe>
Use sub for subtitled anime episodes and dub for dubbed anime episodes.

MW ArtPlayer Endpoint

Use the MW endpoint for the advanced ArtPlayer iframe that supports movies, seasons, episodes, language/detailPath switching, and parent page communication.

Movie URL

https://supaplay.fun/mw/{detailPath}

Episode URL

https://supaplay.fun/mw/{detailPath}/{season}/{episode}

Example iframe embed

<iframe src="https://supaplay.fun/mw/jujutsu-kaisen-english-KD0jSM9ot5/1/1" width="100%" height="500" frameborder="0" scrolling="no" allow="autoplay; fullscreen; picture-in-picture" allowfullscreen> </iframe>
The MW endpoint uses detailPath. The player loads the real subjectId from the H5 detail API internally.

AniList Episode Endpoint

Use the Ani endpoint to embed an anime episode using its AniList ID, episode number, and language type.

Endpoint

https://supaplay.fun/stream/ani/{anilist_id}/{episode_number}/{language}

Example

https://supaplay.fun/stream/ani/21/2/sub

Example iframe

<iframe src="https://supaplay.fun/stream/ani/21/2/sub" width="100%" height="500" frameborder="0" scrolling="no" allow="autoplay; fullscreen; picture-in-picture" allowfullscreen></iframe>
AniList ID: 21
Episode: 2
Language: sub

Valid Embed Parameters

Parameter Description Required
{episode_embed_id} The anime episode/player ID used by the SupaPlay stream endpoint. Yes
{language} Episode language version. Use sub or dub. Yes
Parameter Description Required
{detailPath} The H5/MW detail path, for example jujutsu-kaisen-english-KD0jSM9ot5. Yes
{season} The season number. Use 0 for movies or omit season/episode for movie URLs. No for movies, yes for episodes
{episode} The episode number. Use 0 for movies or omit season/episode for movie URLs. No for movies, yes for episodes

Anikoto, HiAnime, and MW Compatibility

SupaPlay supports two styles of embedding. The classic stream endpoint works with simple episode/player IDs. The MW endpoint works with detailPath values and lets the iframe load the real subject ID, season data, episodes, streams, captions, and language variants internally.

https://supaplay.fun/stream/s-2/{episode_embed_id}/sub https://supaplay.fun/stream/s-2/{episode_embed_id}/dub https://supaplay.fun/stream/ani/{anilist_id}/{episode_number}/sub https://supaplay.fun/stream/ani/{anilist_id}/{episode_number}/dub https://supaplay.fun/stream/ani/{malist_id}/{episode_number}/sub https://supaplay.fun/stream/ani/{malist_id}/{episode_number}/dub https://supaplay.fun/mw/{detailPath} https://supaplay.fun/mw/{detailPath}/{season}/{episode}

MW Parent ↔ Iframe Control Example

The MW iframe can send events to the parent page and receive commands from the parent page.

<iframe id="supaplayFrame" src="https://supaplay.fun/mw/jujutsu-kaisen-english-KD0jSM9ot5/1/1" width="100%" height="500" frameborder="0" scrolling="no" allow="autoplay; fullscreen; picture-in-picture" allowfullscreen> </iframe> <script> const iframe = document.getElementById("supaplayFrame"); window.addEventListener( "message", function(event) { const data = event.data || {}; if (data.type === "episodeChange") { console.log( "Episode changed:", data.season, data.episode, data.detailPath ); } if (data.type === "languageChange") { console.log( "Language changed:", data.language, data.detailPath ); } if (data.type === "playbackEnded") { console.log( "Playback ended:", data ); } } ); iframe.contentWindow.postMessage( { type: "loadEpisode", season: 2, episode: 5 }, "*" ); iframe.contentWindow.postMessage( { type: "nextEpisode" }, "*" ); iframe.contentWindow.postMessage( { type: "changeLanguage", subjectId: "134079758618484744", detailPath: "jujutsu-kaisen-english-gCBS4ln5U9", language: "Original Audio" }, "*" ); iframe.contentWindow.postMessage( { type: "play" }, "*" ); </script>

FAQ

What is SupaPlay?

SupaPlay is an anime video embed API that lets developers place anime episodes, movies, and MW ArtPlayer players on a website using simple iframe URLs.

Does SupaPlay support sub and dub?

Yes. Use sub for subtitled episodes and dub for dubbed episodes on the classic stream endpoint.

What is the MW endpoint?

The MW endpoint uses a detailPath instead of a direct episode player ID. It loads title data, subject ID, streams, captions, seasons, episodes, and language variants inside the iframe.

Can I use Anikoto or HiAnime episode IDs?

Yes. If you scraped or collected IDs from Anikoto or HiAnime-style episode libraries, SupaPlay can use the same type of episode/player ID format.

What is the Ani endpoint?

The Ani endpoint allows you to embed an anime episode using its AniList ID, episode number, and language type. The format is: /stream/ani/{anilist_id}/{episode_number}/{language}
