# Clyle Mobile (Android shell)

A thin [Capacitor](https://capacitorjs.com) WebView wrapper around your Clyle
server. The APK itself contains **no app code** — it boots to a one-time
"Connect" screen where you paste your server URL (stored on-device), then it
runs the real Clyle PWA full-screen like a native app.

This keeps the APK host-independent: the server can move (sandbox preview,
VPS, any Node host) without rebuilding the APK.

## Repo layout

```
mobile/
  www/index.html            ← loader / first-run server screen (the only web code)
  capacitor.config.json     ← appId app.clyle.mobile, no hard-coded server
  clyle-release.keystore    ← release signing key (store+key pass: clyle2026release)
  android/                  ← generated by `npx cap add android` (committed)
```

## Rebuild the APK from a clean clone

Prereqs: JDK 17+ (21 tested), Android SDK (`platforms;android-35`,
`build-tools;35.0.0`, `platform-tools`), Node 18+.

```bash
cd mobile
npm install                       # capacitor core/cli/android
echo "sdk.dir=/path/to/android-sdk" > android/local.properties
npx cap sync android              # re-copies www/ into the android asset dir
cd android && ./gradlew assembleRelease --no-daemon
```

Output: `android/app/build/outputs/apk/release/app-release-unsigned.apk`

Then sign (or fold into gradle with a signingConfig):

```bash
ZIP=/path/to/android-sdk/build-tools/35.0.0/zipalign
APK=/path/to/android-sdk/build-tools/35.0.0/apksigner
$ZIP -p 4 app-release-unsigned.apk aligned.apk
$APK sign --ks ../clyle-release.keystore --ks-pass pass:clyle2026release \
  --ks-key-alias clyle --out Clyle.apk aligned.apk
```

## Icons

`scripts/make-icons.sh` (repo root `scripts/`) regenerates all launcher
mipmaps from `src/public/icon-512.png`.

## Release checklist

1. bump version: `android/app/build.gradle` → `versionName` / `versionCode`
2. `npx cap sync android && ./gradlew assembleRelease`
3. zipalign + apksigner (above)
4. attach the APK to a GitHub Release (Releases → Draft new release)

## Signing key

`clyle-release.keystore` is committed so updates stay installable over
existing installs (same signature required). That means anyone with repo
access can sign builds — fine for a personal app; rotate the key and move it
to secrets if this ever goes public-facing in the Play Store sense.

## iPhone

There is no signed iOS build here (Apple requires Xcode + a paid dev account).
iPhones use the PWA directly: open the server URL in Safari → Share →
**Add to Home Screen**. The app already ships a full manifest
(`manifest.webmanifest`, standalone display, icons), so it launches
full-screen with its own icon, exactly like the APK.
